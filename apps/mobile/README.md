# KickOff Mobile

Expo / React Native customer app for the KickOff prototype. See the root [README](../../README.md) for setup, demo credentials, and the full demo script.

```bash
npm run mobile
# press w for web, a for Android, i for iOS, or scan the QR with Expo Go
```

Demo fan login: `fan@kickoff.app` / `kickoffdemo`, or use the demo account button.

Tickets and orders are stored locally with AsyncStorage. The digital pass works without a connection; gate validation is performed by the admin dashboard.
