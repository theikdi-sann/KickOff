# XClub Admin

Next.js admin dashboard for the XClub prototype. See the root [README](../../README.md) for setup, demo credentials, and the full demo script.

```bash
npm run admin
```

Open http://localhost:3000 and sign in with `admin@xclub.app` / `xclubadmin`.

The mock admin store persists fixture, seating, news, and scan changes in browser localStorage. Use **Orders & passes → Reset demo** to restore the seeded state.
